# Bolsillo clínico

App de estudio y de bolsillo para medicina: vademécum, guías, scores, calculadoras y herramientas de turno.
Funciona sin conexión (PWA) y sincroniza los datos personales con Google Drive (carpeta oculta de la app).

Contenido redactado con ayuda de IA a partir de criterios estándar: verifica dosis y normas vigentes antes de usarlo con pacientes.
